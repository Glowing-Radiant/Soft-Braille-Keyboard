## New

- **Force orientation lock.** A new setting in Keyboard Settings, next to Invert keyboard. It keeps the dots fixed to the phone whichever way the screen turns, for example when the screen flips while the phone lies flat on a table.

## Changed

- **Contracted braille is written when a word ends.** With a contracted table, each new cell can change what the cells before it mean, so the text kept changing and you heard contractions that the next cell undid. Now a word is written when you finish it with a space, new line or any other gesture. Until then each cell is said as uncontracted braille, and deleting a character deletes the last cell you typed.
- **Auto-correct uses the language of the braille table** instead of the system language. If the spell checker doesn't have that language, nothing is corrected, and turning auto-correct on from the keyboard menu says which language is missing.

## Fixed

- Typing a space or new line with no word before it, such as a second space, now says "space" or "new line" instead of "blank".

## Removed

- The quick double delete word gesture from 4.0.0 that deleted all text.
