The first release of this fork, rebuilt for current Android phones and screen readers.

## New

- **Runs on 64-bit phones.** The braille translator, liblouis 3.39, is now built for every CPU type, so the keyboard works on phones that only run 64-bit apps. Braille tables are updated to liblouis 3.39, and Polish computer braille, Brazilian Portuguese and Vietnamese grade 1 are added.
- **Touch pass-through for TalkBack and other screen readers** (Android 11 and later). Turn on the Soft Braille Keyboard accessibility service and the keyboard gets your touches directly while it is open, so you can type braille without pausing the screen reader. Everywhere else the screen reader works as usual.
- **TalkBack braille keyboard gestures.** In Keyboard Settings, Gesture style, choose TalkBack braille keyboard gestures to use the gestures you know from TalkBack's braille keyboard. Swipe up with three fingers for a spoken menu with the features that have no TalkBack gesture.
- **Mixed gestures.** A gesture style where one finger swipes are the classic gestures and swipes with two or three fingers are the TalkBack gestures.
- **User guide in the app.** The guide now comes with the app, works offline and matches the installed version.
- **Speech settings.** Every installed text-to-speech engine is listed, plus System default, with speech rate, pitch and volume settings and a speech test. Speech follows the accessibility volume, like TalkBack.
- **Offer another keyboard without a screen reader.** An optional setting that asks to switch keyboards when the keyboard opens with no screen reader on, for example when someone who can see uses the phone.

## Fixed

- Multi-finger swipes were misread, as only the first finger was followed.
- Phones that take three-finger touches for screenshots or split screen no longer leave those fingers to be typed into the next character. The keyboard explains once which phone setting to turn off.
- When a screen reader such as Jieshuo takes over the touch pass-through region, the keyboard sets it again.
